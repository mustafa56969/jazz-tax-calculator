# Jazz Balance & Tax Calculator 2026

A simple, fast, and mobile-friendly web tool to calculate **Jazz load balance after tax** in Pakistan.

**Live Demo:** [https://jazz-tax-calculator.vercel.app](https://jazz-tax-calculator.vercel.app)

---

## Features

- Instant calculation of net balance after **Withholding Tax (WHT)**
- Reverse calculation (enter desired net balance → get required load amount)
- Quick buttons for common loads: 50, 100, 200, 500, 1000
- Clean Material Design 3 UI
- Fully responsive (mobile-first)
- One-click copy calculation result
- SEO optimized + structured data
- Vercel Analytics included

---

## Tax Formula (2026)

Jazz uses a fixed factor of **0.8696**
